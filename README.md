# Mehdi Mobtahij

I work in an accounting firm while studying for the DSCG.
When something takes me too long, at work or at home, I usually end up building a tool for it. Here are a few.

### [Year-end closing file](https://github.com/medmehdimobtahij-ship-it/dossier-bilan-web)

A web app to prepare a client's year-end closing: review by cycle, revenue and VAT tie-out, corporate tax, the AGM.
It won't let you close the file while something doesn't add up.

### [CRM for an accounting firm](https://github.com/medmehdimobtahij-ship-it/crm-cabinet-comptable)

Prospects, engagement letters, Outlook and Pennylane in one place, so a new client doesn't get lost between emails and Word templates.

### [Patrimoine](https://github.com/medmehdimobtahij-ship-it/patrimoine)

My bank accounts, savings and crypto in one app, and where the money goes each month. I use it every day. There's a [demo](https://medmehdimobtahij-ship-it.github.io/patrimoine/).

### [CROUS alert](https://github.com/medmehdimobtahij-ship-it/alerte-crous)

A small bot that watches for student housing and pings my phone when something frees up, because refreshing the page all day wasn't working.
